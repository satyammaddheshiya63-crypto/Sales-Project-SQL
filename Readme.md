SQL Sales Analysis Project


 Project Overview


This project focuses on analyzing a sales dataset using SQL to extract meaningful business insights.
The goal is to understand sales performance, product trends, regional contribution, and profitability.


---


 Tools & Technologies


* SQL (MySQL Workbench)
* Dataset (Sales Data)
* GitHub for version control


---


 Dataset Details


The dataset contains the following columns:


* Id
* Product_Name
* Quantity
* Unit_Price
* Sales
* Region
* Category
* Sub_Category
* Date
* Profit


---


Key Analysis Performed


 1. Business Overview


* Total Sales & Profit
* Total Orders
* Average Order Value
* Total Quantity Sold


2. Product Analysis


* Top-selling products
* Product-wise revenue and profit
* Top 3 products
* Lowest performing products


3. Region Analysis


* Region-wise sales and profit
* Top-performing region
* Regional ranking


4. Category Analysis


* Category-wise performance
* Profit contribution
* Sub-category insights


5. Time-Based Analysis


* Monthly sales trend
* Daily sales trend
* Month-over-Month (MoM) growth
* Peak sales dates


6. Advanced SQL Analysis


* Window functions (RANK, ROW_NUMBER, LAG)
* Running totals
* Pareto Analysis (80/20 rule)
* Sales growth analysis


---
Key Insights


* Laptop is the top-performing product contributing the highest revenue
* West region shows the highest overall sales
* Electronics category generates the highest profit
* Sales show a stable trend with occasional spikes
* A small number of products contribute to the majority of revenue (Pareto Principle)
